# How to Screen Printing

An interactive browser-based workshop that guides you through the complete process of creating a two-color screen print.

> 一个可以亲手操作的线上丝印工坊：八道工序，一张双色版画。

## About

Screen printing is easier to understand by doing.

This project transforms the workflow of a real screen-printing studio into an interactive web experience. Instead of simply reading instructions, users complete each stage themselves—from separating the artwork and preparing the screen to registration, printing, curing, and downloading the final result.

Mistakes also become part of the experience: exposure can fail, registration can shift, and those small imperfections will appear in the final print.

## The Eight Steps

1. Color separation and film output
2. Stretching the screen
3. Coating the photo emulsion
4. UV exposure
5. Washing out the stencil
6. Registration and alignment
7. Inking, squeegeeing, and two-color printing
8. Heat curing and downloading the final print

## Features

- Eight sequential, hands-on interactions
- Canvas-based drawing and simulation
- Real-time feedback for tension, coverage, exposure, and registration
- Final artwork reflects the user’s printing accuracy
- Mouse and touch controls
- Downloadable finished print
- Responsive single-page design
- No external libraries or build tools required

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API

## Run Locally

Download the repository and open `index.html` in your browser.

No installation or build process is required.
